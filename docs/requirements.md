## 项目概述

### 1.1 项目背景

随着移动支付的普及，个人和家庭的消费记录越来越难以追踪。传统的记账方式存在以下痛点：

- **记录繁琐**：需要手动输入大量信息
- **数据分散**：家庭成员各自记录，无法汇总
- **分析困难**：缺乏多维度的统计分析
- **同步不便**：多人协作时数据无法实时同步

### 1.2 产品定位

CoinNote 是一款面向家庭用户的记账小程序，主打：

- **简洁易用**：3秒完成一笔记录
- **家庭协作**：多人共同记录，实时同步
- **智能分析**：多维度消费统计
- **离线优先**：无网络也能正常使用

### 1.3 目标用户

| 用户类型 | 特征 | 需求 |
|----------|------|------|
| 年轻家庭 | 25-35岁，已婚有孩 | 家庭收支管理 |
| 情侣 | 20-30岁，共同生活 | 共同消费分摊 |
| 合租室友 | 20-35岁，共享开支 | 公共费用记录 |

### 1.4 核心价值

```
┌─────────────────────────────────────────────────────────┐
│                    CoinNote 核心价值                      │
├─────────────────────────────────────────────────────────┤
│  ✅ 简化记账流程 → 3秒完成一笔记录                        │
│  ✅ 促进家庭协作 → 多人共同记录，实时同步                  │
│  ✅ 智能消费分析 → 多维度统计，洞察消费习惯                │
│  ✅ 保障数据安全 → 离线优先，云端备份                      │
└─────────────────────────────────────────────────────────┘
```

### 3.3 功能详细说明

#### F001 - 微信登录

**功能描述：**
用户通过微信授权登录小程序，无需注册账号。

**用户故事：**
```
作为 一个新用户
我想要 通过微信一键登录
以便 快速开始使用小程序
```

**功能要求：**
- 支持微信一键登录
- 自动获取用户头像和昵称
- 首次登录自动创建账号
- 登录状态本地持久化
- 支持静默登录（已授权用户）

**验收标准：**
- [ ] 点击登录按钮可唤起微信授权
- [ ] 授权成功后自动进入首页
- [ ] 用户信息正确显示
- [ ] 重启小程序无需重新登录
- [ ] 未授权用户显示引导页面

## 术语表

| 术语 | 说明 |
|------|------|
| 消费记录 | 用户记录的一笔消费，包含金额、分类、日期等信息 |
| 分类 | 消费的类别，支持二级分类（如：餐饮 → 午餐） |
| 标签 | 消费的标记，用于辅助分类（如：日常、必要、冲动消费） |
| 家庭 | 多个用户组成的组，可以共同记录消费 |
| 邀请码 | 家庭创建时生成的6位代码，用于邀请成员加入 |
| 离线优先 | 设计模式，优先使用本地数据，后台同步到服务器 |
| 增量同步 | 只同步变更的数据，减少数据传输量 |
| JWT | JSON Web Token，用于身份认证的令牌 |
| API | Application Programming Interface，应用程序接口 |
| UI | User Interface，用户界面 |
| UX | User Experience，用户体验 |
| MVP | Minimum Viable Product，最小可行产品 |
| P0/P1/P2/P3 | 优先级等级，P0最高，P3最低 |
